# Reaproveitamento do EventPlus

O backend EventPlus foi usado como referência para acelerar a construção. Foram preservados os conceitos de ASP.NET Core Web API, Entity Framework, autenticação JWT, BCrypt, organização por controllers/repositories e Swagger.

O domínio de eventos, comentários, presenças, Cloudinary e moderação de imagens foi removido. A nova solução foi reconstruída com entidades educacionais e componentes de segurança/monitoramento.
