# n8n - fluxo de alertas
O arquivo `edusecure-alert-workflow.json` contém o fluxo para receber o webhook do Alertmanager e registrar um incidente na API.

Na primeira execução: abra http://localhost:5678, conclua o cadastro local do n8n e importe o JSON em **Workflows > Import from File**. Depois ative o workflow.
